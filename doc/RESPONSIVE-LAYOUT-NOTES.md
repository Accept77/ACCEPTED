# 반응형 탐색 화면 레이아웃

## 모바일 탐색 패널

- 모바일에서는 지도 영역을 `40dvh`, 맛집 패널을 `60dvh`로 배치합니다.
- 검색창 오른쪽에 필터 아이콘을 두고, 지역·분류·방문 상태 필터는 모바일 바텀 모달에서 표시합니다.
- 필터 모달은 최대 `85dvh` 높이와 자체 세로 스크롤을 사용해 목록 영역을 가리지 않습니다.
- 맛집 목록은 `min-h-0 flex-1 overflow-y-auto` 구조로 남은 패널 높이를 사용합니다.
- 목록 패널 상단 경계에 떠 있는 화살표로 목록을 접으면 목록 바(`h-14`)만 남고, 지도는 `calc(100dvh - 3.5rem)`까지 확장됩니다. 같은 위치의 위쪽 화살표로 다시 펼칠 수 있으며 지도에서 장소를 선택해도 목록이 자동으로 펼쳐집니다.
- 맛집 상세보기와 상세 로딩/오류 화면은 모바일에서 `100dvh` 전체 화면을 사용합니다.
- 맛집 상세보기 하단에서 네이버 지도를 열거나 식당명·주소·네이버 지도 링크를 공유할 수 있습니다. 공유 API를 지원하지 않는 브라우저에서는 링크를 클립보드에 복사합니다.

## 데스크톱 동작

- `lg` 이상에서는 필터가 항상 펼쳐지고 지도·목록의 기존 좌우 분할 레이아웃을 유지합니다.
- 모바일 전용 필터 토글은 데스크톱에서 숨깁니다.

## 검증

- `npm.cmd run lint`
- `npm.cmd exec tsc -- --noEmit`
- `npm.cmd run build`
