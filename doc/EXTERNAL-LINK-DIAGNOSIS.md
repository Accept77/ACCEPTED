# 외부 링크 중복 이동 진단

## 증상

상세 모달의 `네이버 지도` 버튼을 누르면 네이버 지도가 새 링크로 열리는 동시에 현재 홈페이지도 네이버 지도로 이동할 수 있었습니다.

## 원인

브라우저 플랫폼이 `window.open()`의 반환값을 확인한 뒤 반환값이 없으면 `window.location.assign()`으로 현재 페이지를 이동시키고 있었습니다. 일부 브라우저나 WebView에서는 외부 링크가 열려도 `window.open()`의 반환값이 `null`이 될 수 있어 두 동작이 겹칠 수 있습니다.

## 변경 내용

- 브라우저 외부 링크는 새 창 열기만 수행하고 현재 페이지 이동 fallback을 제거했습니다.
- 상세 모달의 네이버 지도·이미지 출처 링크는 공통 클릭 처리기를 사용합니다.
- 커스텀 외부 링크 처리가 가능한 플랫폼에서는 기본 `<a>` 이동을 막고 플랫폼 호출 한 번만 수행합니다.
- 외부 링크 호출 실패 시 두 번째 `window.open()`을 호출하지 않도록 해 중복 열림을 방지했습니다.

## 검증

`window.open()`이 `null`을 반환하는 환경을 모의해도 외부 열기 횟수는 1회이고 현재 페이지 이동은 0회인지 확인했습니다.
