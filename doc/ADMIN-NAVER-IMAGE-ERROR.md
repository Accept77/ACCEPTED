# 관리자 네이버 이미지 오류 처리

## 원인

운영 환경에서 네이버 장소 등록 사진을 클릭하면 네이버 이미지 다운로드나 R2 업로드 과정에서 발생한 서버 액션 오류가 React 오류 코드 `#441`로 표시될 수 있습니다. React는 운영 환경에서 서버 오류의 상세 메시지를 클라이언트에 그대로 전달하지 않습니다.

## 적용 내용

`importImageFromNaver` 서버 액션이 이미지 저장 성공·실패를 직렬화 가능한 결과 객체로 반환하도록 변경했습니다. 따라서 예상 가능한 네이버 이미지 또는 R2 오류는 페이지 전체를 깨뜨리지 않고 관리자 폼의 오류 영역에 표시됩니다.

인증 실패에 따른 리디렉션은 기존처럼 `requireAdmin`에서 처리합니다. 이미지 저장 실패 시에는 현재 폼에 남아 다시 시도할 수 있습니다.

## 이미지 용량 제한

관리자 직접 업로드와 네이버 이미지의 R2 저장 제한을 장당 10MB로 통일했습니다. Supabase 스키마에 남아 있는 이미지 버킷 제한도 10MB로 맞췄습니다.

관리자 메인 화면의 `누락 사진 자동 보완`은 이미지가 없는 식당의 저장된 네이버 후보를 다시 검사합니다. 지원 가능한 첫 이미지를 R2에 저장한 뒤 DB의 대표 이미지 경로를 갱신하며, DB 반영에 실패하면 방금 생성한 R2 객체를 삭제합니다.
