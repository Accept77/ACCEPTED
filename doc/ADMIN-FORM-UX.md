# 관리자 등록·수정 폼 개선

## 적용 내용

- 등록·수정 페이지의 콘텐츠 최대 폭을 `max-w-screen-2xl`로 확장했습니다.
- 데스크톱(`lg`)에서는 네이버 장소 검색과 저장 액션을 전체 폭으로 배치합니다.
- 데스크톱에서는 큐레이션 입력과 이미지 관리를 2열로 나누고, 모바일에서는 1열로 유지합니다.
- 이미지 미리보기와 후보 목록도 데스크톱 카드 폭을 활용하도록 확장했습니다.
- 대표 사진 관리 영역은 접지 않고 항상 펼쳐서 표시합니다.
- 직접 등록 화면에서 네이버 장소를 선택하면 이미지 후보를 조회하고 첫 번째 저장 가능한 썸네일을 R2 대표사진으로 자동 추가합니다. 기존 이미지가 있으면 자동으로 덮어쓰지 않습니다.
- 네이버 장소 검색의 정수 좌표는 위·경도로 변환해 저장하며, 기존에 정수 좌표로 저장된 식당도 조회 시 정규화해 지도와 거리 계산에 사용합니다.
- 저장이 성공하면 내부 이전 페이지로 돌아갑니다.
- 직접 URL로 진입해 이전 페이지가 없거나 외부 페이지에서 진입한 경우에는 `/admin`으로 이동합니다.
- 관리자 목록에서 수정하거나 등록할 때 현재 페이지와 검색·필터 조건을 `returnTo`로 전달해 저장 및 취소 후 동일한 목록으로 복귀합니다.

## 저장 실패 동작

저장 요청이 실패하면 현재 폼에 오류를 표시하고 페이지를 이동하지 않습니다. 이미지 업로드 중이거나 저장 중일 때는 저장 버튼을 비활성화해 중복 요청을 막습니다.
