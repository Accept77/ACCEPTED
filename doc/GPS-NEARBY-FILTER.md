# GPS 주변 필터

## 적용 내용

공개 화면에서 `내 위치 찾기`를 누르면 브라우저 위치 권한으로 현재 좌표를 가져옵니다. 위치를 성공적으로 가져온 뒤에는 기본 `내 주변 3km` 거리 필터를 자동으로 활성화합니다.

현재 좌표는 지도 중심과 현재 위치 마커에 사용되고, 같은 상태의 주변 거리 조건이 맛집 리스트와 메뉴추천 후보에도 함께 적용됩니다. 사용자는 필터의 `1km`, `3km`, `5km`, `전체` 버튼으로 범위를 변경하거나 해제할 수 있습니다.

행정동명을 별도로 역지오코딩하지 않고 거리 기준을 사용합니다. 이 방식은 추가 주소 API 호출 없이 저장된 위도·경도 데이터를 활용하며, 행정구역 경계 때문에 가까운 식당이 제외되는 문제를 줄입니다.

## 필터 초기화 표시

활성 필터가 있을 때 표시되는 `초기화` 버튼은 회색 대신 연한 장밋빛 배경과 빨간색 텍스트를 사용합니다. 필터 해제라는 보조 액션이 눈에 잘 띄면서도 삭제 버튼처럼 과하게 위험해 보이지 않도록 했습니다.
