# GPS 주변 필터

## 적용 내용

공개 화면에서 `내 위치 찾기`를 누르면 브라우저 위치 권한으로 현재 좌표를 가져옵니다. 위치를 성공적으로 가져온 뒤에는 사용자가 선택한 거리 필터가 유지되며, 기본값으로 주변 필터를 자동 적용하지 않습니다.

현재 좌표는 지도 중심과 현재 위치 마커에 사용됩니다. 사용자는 위치를 확인한 뒤 필터의 `1km`, `3km`, `5km`, `전체` 버튼을 직접 선택해 주변 범위를 적용하거나 해제할 수 있습니다. 선택하지 않으면 전체 맛집을 표시합니다.

행정동명을 별도로 역지오코딩하지 않고 거리 기준을 사용합니다. 이 방식은 추가 주소 API 호출 없이 저장된 위도·경도 데이터를 활용하며, 행정구역 경계 때문에 가까운 식당이 제외되는 문제를 줄입니다.

## 필터 초기화 표시

활성 필터가 있을 때 표시되는 `초기화` 버튼으로 검색어, 지역, 분류, 방문 여부, 주변 거리 필터를 한 번에 해제할 수 있습니다.
